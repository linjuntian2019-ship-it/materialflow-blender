# MaterialFlow for Blender

**从材料外观，到可编辑的物理属性。**

为 Blender 动画作者制作的本地材料识别与固液交互原型。
目标是减少“物体进入液体之后该怎么运动、水面如何响应”的重复设置。

## 当前做到哪一步

这是可运行的实验原型，还不是通用的固液耦合插件。

| 功能 | 当前状态 |
| --- | --- |
| 材料建议 | 本地 Apple DMS46 分析 12 个渲染视角，无需 GPT API 账号 |
| 自动体积 | Blender evaluated mesh + BMesh 体积计算，考虑缩放和场景单位 |
| 固体 | 手动确认类型后输入密度或质量，自动换算另一项 |
| 液体 | 可保存密度、动力黏度、表面张力，目前尚未接入演示求解器 |
| 无法识别 | 保留手动输入，不让模型单次判断直接设置物理参数 |
| 木块落水 | 1 m 实心方块的自由落体、入水、浮起及 Mantaflow 水花演示 |

**AI 判断的是外观材料类别，不会测量密度。** 灰色网格、涂层、内部空腔、
木材含水量等都可能造成歧义。像素占比不是“准确率”。默认密度只是示例值。

## 安装与使用

1. 从 Releases 下载 `materialflow-blender-v0.3.1.zip`。
2. Blender 偏好设置 → 插件 → 从磁盘安装，选择 ZIP 并启用 MaterialFlow。
3. 在 3D 视图按 `N`，进入“材料物理”面板，选中物体。
4. 可直接手动设置物理属性；需要 AI 时，按[安装指南](docs/SETUP.md)配置独立 Python、模型和类别文件。
5. 重现落水演示：使用应用缩放后的 1 m 方块，确认固体密度 600 kg/m³，
   点击“创建木块落水场景”，保存文件，再点击“烘焙液体与水花”。

已测试 Windows + Blender 5.2.2 LTS + RTX 4080。AI 当前需要 NVIDIA CUDA。
Apple 指模型来源，不代表当前支持 Apple Silicon。手动属性与演示无需安装 AI 模型。

## 必须说明的边界

木块运动由近似浮力、阻力和阻尼计算，再驱动 Mantaflow 水体产生响应。
这属于**单向耦合**：水体的即时流动不会反过来修正木块运动。
当前演示水密度固定为 1000 kg/m³，重力为 9.81 m/s²；液体面板中的自定义
密度和黏度还没有用于演示。因此不能宣称已经支持任意特殊液体。

任意形状、滑入液体、重物沉底、底部碰撞和双向耦合仍在规划中。
修改参数之后需要重新生成运动并烘焙，旧动画不会自动改变。
下载包不包含模型权重和大体积缓存；示例脚本能重新生成场景。

下一阶段将先把液体参数真正接入物理计算，再拓展形状、入水速度和碰撞。
